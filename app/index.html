How to Use the Downloader

  1. Paste a public media or playlist link. A green check means the link is verified; select the check to edit it.
  2. Choose each row's Converting to format. Use Add URL to process several links; a repeated link must use a different output.
  3. Process prepares one link; Process URLs prepares several. Every row must be filled and verified first.
  4. When processing finishes, choose Save beside a file to download it to your device.

Download Methods

  • Original: Keep the original media format.
  • H264: Create a broadly compatible video, up to 120 minutes.
  • GIF: Create a silent GIF, up to 10 minutes.
  • MP3: Extract the audio.
  • Transcribe: Create a timestamped written transcript.

Supported Sites

These services—and many others—work with media and playlist links. Playlists are limited to 50 items and run in order.

Recent Files & Privacy

  • Your Downloads are private to this browser and permanently removed after 72 hours.
  • You may make a private file public for 72 hours. That choice cannot be reversed.
  • Public Downloads are visible to everyone without naming who shared them.
  • Select a title to preview media or read a transcript.
  • Use to copy a complete transcript.
  • Use to save, to make public, to delete, or to refresh.
  • Transcription runs on this server's CPU, so long videos may take a few minutes.
